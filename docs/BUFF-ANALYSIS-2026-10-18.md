# 全部buff强度分析与评价方法

日期：2026-10-18。分析基线：当前PC源码MOD_BUILD65及上一轮已确认的三项加强。本次只创建分析资料，没有调整任何游戏数值、词条、权重或代码。对“早期buff多数已调整好”的处理是：用它们校准收益与代价，不重新追求全表数值一致。

范围：植物／全局目录共113条（ID0—112），其中9条全局、48条原植物升级、56条后续植物词条；4条不进入候选池（ID20、25、42、58），当前可入池109条。另外单列9条僵尸强化。这里“可入池”是目录白名单状态，实际还要有对应植物、未满层、满足互斥和当前抽取规则。

结论来自源码核对与公式分析，没有新增实机对局数据。文中“强”“偏条件”“优先观察”是设计判断，并非胜率排名；理论上界不当作实测输出。本次不建议普遍增强后续词条，也不据此削弱已经允许的强组合。

## 1. 应当评价什么

每条buff分三层看：**单拿是否有收益；当前阵容能兑现多少；成型组合上限有多高。** 只看其中一层都会误判。还要同时写清前期／后期、稀疏／密集、普通敌人／Boss、有限闯关／无尽的差别。

对一个选择，真正要比较的是：**拿到它后的整套阵容，在剩下这局里多解决了多少问题，相比同屏其他选择付出了什么。** 额外伤害、避免漏怪、节省卡片循环、缩短成型、提高拿到核心词条的机会，都属于收益。

可用下面的核算框架，但不要强行把所有效果折成一个分数：

```
常规有效输出 ≈ 单次有效伤害 × 实际出手频率 × 平均有效命中数 × 可工作时间比例
新增有效输出 = 有buff时的整阵有效输出 − 无buff时的整阵有效输出
实际使用频率 ≤ min(卡片可用频率、阳光支持频率、合法位置/目标提供频率、操作支持频率)
```

乘积模型适合拆解原因，不替代完整结算：乘区、伤害上限、护甲、过量伤害、护心、特殊目标免疫都要另算。尤其不能把已经乘过的覆盖和命中率重复乘一次。

## 2. 决定强度的十二组因素

| 因素 | 应检查什么 | 本项目中的典型例子 |
|---|---|---|
| 植物底子与覆盖对象 | 强化一株还是全队？初始几发？射程、费用、占格如何？ | 小喷1→3发的200%与全队火力25%不能直接横比；前线短射程是代价。 |
| 增量而非最终总能力 | 本体已有多少？新词条真正增加哪部分？ | 双子自动捡阳光是本体能力，聚光增幅新增20%价值；黄油飞溅只计额外控制。 |
| 出手频率与工作时间 | 有没有空道、缩头、咀嚼、装填、无敌阶段？ | 无畏、调度、双向调兵是提高有效工作比例；疾雾固定频率不能再乘急袭。 |
| 平均命中数与真实范围 | 弹能穿多少只？邻行有人吗？会不会分摊？ | 冰瓜极寒爆裂取消分摊，密度越高收益越大；冰晶只有打到人才有价值。 |
| 触发条件与首次收益 | 要被啃、死亡、转化、消化完成还是过关？到收益前能否活下来？ | 蒜气扩散、亡语、反哺、重摇基金都不能按始终触发计算。 |
| 伤害形态与击杀线 | 固定、百分比、即死、持续伤害分别吃什么规则？ | 蚀心孢子取当前本体生命；巨人克星固定1000；护心只挡第一次大额命中。 |
| 控制覆盖与抗性 | 是冻结、减速、换道还是击退？刷新能否持续覆盖？ | 免硬控克黄油/冻结/魅惑；软控缩时不改幅度，频繁续时可能抵消缩短时长。 |
| 有效生命与可恢复生命 | 是否真会受伤？能否熬过一次爆发？固定扣血还是普通啃咬？ | 耐砸改变生存机制；钢壳牺牲普通耐久；血量成长可扩大百分比治疗。 |
| 阳光、卡槽、格子与操作 | 哪个资源才是当前瓶颈？省一个是否仍被另一个卡住？ | 0费植物仍受卡片冷却和格子限制；加农炮装填快了仍需瞄准。 |
| 回报时点与剩余关时 | 现在救命还是几关后回本？重新铺场还是保留草坪？ | 催长只帮助新种小菇；满阵无尽中免费种植的边际收益下降。 |
| 层数、乘区与替代 | 同轴线性还是跨轴乘算？有没有互斥、固定值覆盖、负协同？ | 窝瓜次数加法再乘倍数；引燃会降低概率瓜弹的相对增伤；磐石覆盖最终血量。 |
| 获取机会与成长环境 | 星级、权重、卡池资格、同屏竞争、借用和敌方成长怎样？ | 三星难拿也占一次选择；战略轰炸额外降权；后期固定1000与高血敌人的比值下降。 |

## 3. 用成熟条目校准，避免三个常见误判

**第一，不要求所有二星都提供相近百分比。** 火力服务全队，连发只服务一种植物。免投虽然直接减掉100%费用，却不能取消冷却、卡槽、格子和植物基础输出。机枪超频是一星，但植物直种450阳光、基础种植冷却30秒，词条只能拿一层。这里的星级同时承担稀有度和机制定位，不能当作一条统一的战力标尺。

**第二，新增机制必须算“实际多做了多少”，不是重新计算本体。** 冰瓜已有冰缓，三星新增加的是冰浪伤害和冻结窗口；它的全额群体伤害主要由二星极寒爆裂承担。双子三星并不存在，二星聚光增幅也不是首次赋予自动收集。坚果已有商店包扎术时，1星词条的新增价值是放宽重种伤势门槛。

**第三，早期已成熟的强条目是参照物，不是待削弱名单。** 连发、弹幕、瓜幕、0费种植、疾雾、炮转化各自已形成清楚路线。分析后续buff时应检查它是否也有清楚的独立收益与合理代价，而不是为了数字整齐改动这些路线。

### 几组可以直接计算的参照

| 例子 | 理论收益 | 实战修正 |
|---|---|---|

| 急袭4层 | 间隔0.8⁴=0.4096，频率约×2.44 | 对固定频率/独立计时不套用；整数帧、有效目标和动画兑现需另看。 |
| 同时首层火力、首层精准、急袭4层 | 普通受益子弹理论倍率1.25×1.15÷0.8⁴≈3.51 | 这是相同命中率下的持续火力，不代表全局收益或所有特效。 |
| 线性叠层 | 1→2份为+100%，2→3份为+50% | 面板每层加同样数值，边际百分比仍递减。 |

### 获取机会也属于强度，但权重不等于固定出率

普通专属词条的1／2／3星基础权重为12／6／1；经济类再乘3，全局系数2.5，1／2星全局最终再减半并按整数取整。实际抽取还统一乘16以表达战略轰炸的小权重：这一共同因子不改变概率。

| 词条类型 | 去除共同×16后的相对权重 | 解释 |
|---|---:|---|
| 普通专属1／2／3星 | 12／6／1 | 同一合法候选池中比较，不是12%／6%／1%。 |
| 经济专属1／2星 | 36／18 | 适用于源码列入经济清单的条目，金盏花产档案币不自动享受该加权。 |
| 火力、急袭等非经济全局2星 | 8 | 6×2.5后再减半，整数舍入；覆盖广且相对容易进入构筑。 |
| 扎根、爆破、精准等非经济全局1星 | 15 | 是抽取权重，不是强度评分。 |
| 丰饶、速种等经济全局2星 | 23 | 6×2.5×3后再减半取整。 |
| 天降 | 45 | 当前经济全局1星，出现机会较高，单层拿到后退出。 |
| 排山倒海 | 3 | 三星全局不执行低星全局减半。 |
| 战略轰炸 | 0.25；已有炮转化时0.0625 | 实际权重分别4／1，普通三星为16；持战略后炮转化反向降到普通值1/4。 |

三星即使对局内很强，也可能难在有限关数里拿到并配齐；较弱但容易获得的组件可能支撑更稳定的路线。同屏同株去重、互斥和未选条目下一屏冷却会改变组合成型机会，因此不能只比较孤立权重。无限层条目会一直占据成长选择，限1层机制拿到后则退出候选，二者的长期成长轨迹不同。

经济、控制和伤害还会互相反馈：减速增加敌人在射程内的时间，也可能增加穿透／溅射的有效命中数；但敌人再生会在多出来的时间回血。没有再生时有效的拖延策略，在高再生时可能只是延后漏怪。联机不同草坪的实际来怪压力、漏怪转交、资源赠送和临时借用，也会改变“这次该拿什么”。本表不把一号位或单机结论视为所有席位的统一结论。

## 4. 源码中必须分清的口径

- 当前毁灭菇湮灭是6000，深冻是每层额外6秒，窝瓜连砸当前不设叠层上限；头文件/旧总表存在旧数值，不能拿旧值做排名。
- 排山倒海当前每次最多补1株，先下后上，不是上下各补1株。其目录文字容易让人误读为三株总量；本报告按实际两株总量评价，没有修改文字或行为。
- 路灯暮光表述“攻速×0.75”实际是攻击间隔×0.75，即频率约×1.333/层。疾掘同样应按等待缩短理解，不能把它解读为越拿越慢。
- 腐臭之息实际按层数减速20%/40%，南瓜再生按层数每跳回10%/20%，伤口加深按层数30%/60%；表里一些描述只写首层。普通冰缓覆盖时，腐臭／霜甲不再机械与它连乘；没有普通冰缓时二者在现有路径可相乘。仙人掌20%只补到更强移动减速之前，不与已有更强效果叠乘。
- 当前金币能用于重摇和商店。旧资料“产币无用途”已过时；但档案钱包余额不同，会影响金盏花和免费重摇的实际边际价值。
- 专属buff的候选资格是拥有对应植物，不代表本关一定带卡、已经种下或有合适目标。临时借用取同一专属词条双方最高层，不是把两份层数加起来；全局buff不随借用共享。

## 5. 全部植物／全局buff逐项分析

评价以首层和正常可达组合为主。“条件型”不等于建议加强；“强机制观察项”也不等于建议削弱。每条按实际角色核算，4条不入池明确标记。

“效果封顶”与“是否还能抽到”要区分：有限模式部分数值条仍可叠到效果饱和；新无尽候选另有满效果退出规则。三种关底Boss还有各自血量、动作、免硬控与软控缩时规则，不能把普通僵尸结论直接搬过去。

再生的简单门槛是：每秒有效本体伤害必须超过 `0.005 × 再生层数 × 最大本体生命`（上限25%/秒），才能维持净削血；护甲、伤害上限与攻击窗口还会进一步影响实际情况。以100000最大本体生命、1层再生为例，每秒回500。这个例子用于说明机制，不是本项目实测常见敌人血量。

## 7. 三项最新加强应如何观察

### 胆小菇蚀心孢子

公式保持 `min(5000, floor(当前本体生命×5%))`。当前生命不足16000时，与原800上限版的百分比额外伤害相同；16000—100000之间新增收益持续扩大；到100000才触新上限。由此可知，提高上限主要修复的是高血目标后期增长，并没有把普通低血敌人一律强化6.25倍。

在不触顶、无护甲/回血/减伤且忽略基础伤害的理想条件下，连续14次5%当前生命命中约使剩余生命降至48.8%，而不是20次固定扣5%最大生命直接杀死。多株与攻速可以提高命中次数；这是已允许的组合。不把它改成每秒共享额度。

重点看：**高血Boss处理时间、普通群怪占用火力、缩头停工比例、护心和再生环境**。固定上限与当前生命递减是两重限制；附加伤害还要正常走已有护甲结算。

### 忧郁菇emotional damage

满足留空条件时，伤害从60到100，较上一版提高约66.7%；回血从每命中2%到4%，绝对翻倍。若最大生命1000，一次雾爆命中5只且都有合法命中，理论该次回200；一轮多次雾爆分别命中会继续回血，但只能回到最大生命。这是命中数与频率带来的组合，而非无条件常驻回血。

整阵应比较**留空阵形与常规密植阵形**。若有效攻击中仅有比例q满足留空条件，忽略其他变化，基础伤害的平均倍率是 `1+4q`，不是始终×5。q=25%时仅为×2。幽环能跨过留空圈工作，耐砸和扎根提高接敌容错；南瓜和相邻复制株会破坏条件。排山倒海种出邻株后，本词条会因此关闭，除非后续主动处理布局。

重点看：**每格阵容火力、实际接敌时间、孤立满足比例、单体/Boss时的低命中回血、满血溢出与爆发致死**。不能只拿一株×5对比一株普通菇，就宣布整套阵容五倍强。

### 冰瓜冰川推进

旧版平均每次主攻击附带120/6=20基础冰浪伤害，新版为240/3=80，**平均冰浪伤害四倍、触发频率两倍**。这只针对新增冰浪，不是整株总伤害四倍；常规瓜弹和二星溅射仍独立存在。

按3秒的名义攻击周期估算，单株约9秒出一道冰浪；急袭4层后名义约3.69秒出一道。真实周期有随机帧与动作兑现，冻结还有飞行到达时间，因此这些是估算。多株交错可提高覆盖，但不能假定天然实现永久冰冻；Boss及免硬控直接取消冻结部分。

重点看：**冰浪实际命中人数、从种下到第一次冰浪的等待、三行覆盖、攻速成型后的冻结占空、Boss伤害贡献**。加强后已经有可观独立伤害，是否还弱应由这些数据判断。

## 8. 下一步值得优先记录的项目

| 优先级 | 对象 | 需要分清的问题 |
|---|---|---|
| 高 | 三项Build65加强 | 高血、稀疏、密集、免硬控四类场合各兑现多少；先看新值表现，不立即再加。 |

| 中 | 金盏花三条、点石成金、镀金、保护伞血量、灯火、疾掘 | 强度随钱包、关长、场景和敌人构成变化很大。部分是低星功能条，不要求在每关都等于输出核心。 |

一条buff最少记录：选择时阵容与模式、层数／组合、投入阳光和格子、第一次收益时间、触发机会数与成功数、有效命中数、造成的有效伤害／有效治疗／控制时间、是否避免漏怪、对照可选项。治疗只算缺血时真正恢复的部分，控制只算确实延迟了威胁的部分，范围伤害扣掉溢出；经济同时记“是否来得及花掉”。

还应记没选它的情况。只看赢局里已成型的组合，会高估稀有词条；只看第一次抽到后立刻的效果，又会低估成长与构筑经济。一次选择的代价不仅是星级，还包括同屏放弃的其他选项。
