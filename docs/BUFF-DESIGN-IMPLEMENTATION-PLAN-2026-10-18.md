# Buff设计汇总与实现计划

更新：2026-10-18。依据本聊天截至“好，总结所有上面设计，撕甲改成2星，作实现计划”的用户决定。

本文只整理设计和实施计划，不执行新一轮游戏代码修改。区分已实现、已确认待实现、待定方案；历史报告里的建议不自动成为定案。

## 2. 已确认、待实现：磁力菇

### 2.1 现有两条

| 词条 | 星级/层数上限 | 计划规则 |
|---|---|---|
| 充磁 | 2星/3层 | 吸取间隔由每层×0.8加强为每层×0.5；冷却计时15/7.5/3.75/1.875秒 |
| 卸甲飞掷 | 2星/2层 | 保留吸到装备后每层基础1200伤害；与撕甲的具体联动见待定项 |

吸取动画和状态切换必须跟上缩短后的冷却，不能只改计时、满层却被原动作拖慢。现有普通装备吸取也受充磁加强。

### 2.2 新增「磁力撕甲」

- **2星、1层**。用户最新明确把此前候选三星改为二星。
- 允许磁力菇针对橄榄Boss的头盔作用；每次破坏**3000头盔耐久**。
- 使用磁力菇既有充磁周期；多株可以共同作用于同一Boss。
- 保留现有覆盖范围：上下各两行约束，通常半径270像素，啃食目标320像素；不是全图或无限跨行。
- 普通敌人的金属装备继续按原规则直接吸走；没有撕甲词条时继续保留Boss吸取免疫。
- 头盔未耗尽时继续戴着，耗尽时再正常拆盔；不允许一次直接吸走橄榄Boss完整头盔。
- 此机制直接针对防具，不改变其他百分比伤害的本体生命基线，不附加Boss定身或位移。

五人标准末关、无铁壁等额外生命强化，橄榄Boss本体60768、头盔315360。假设满层充磁、初始已就绪且始终能命中，忽略其他伤害和动画额外延迟，单次3000：1/3/5/10株从第一轮至拆盔约197/66/39/19秒。只是设计估算，不是实战结果；五人不等于只能种五株磁力菇。

### 2.3 待定的磁力细节

| 问题 | 当前状态 | 实施建议，尚不是用户定案 |
|---|---|---|
| 每次撕甲是否触发卸甲飞掷 | 上一轮用“如果触发”讨论，未明确决定 | 建议碎片也触发；满层额外2400基础伤害/次，需要一起核算拆盔速度 |
| Boss目标优先级 | 提出过Boss优先，未明确决定 | 有撕甲时优先范围内带盔橄榄Boss，其余目标照旧 |
| 不足3000的剩余耐久 | 技术边界需落实 | 只消耗剩余头盔耐久，撕甲本身不把溢出量转成本体伤害 |
| 头盔已无耐久 | 技术边界需落实 | 不再锁定该Boss进行无意义的撕甲或消耗充能 |

其中前两项会改变实际强度和目标选择，实施前需要明确。后两项作为“只破甲”的边界处理。

## 3. 已确认方向、数值待定：黄油持续伤害

用户决定取代此前瞬间黄油重击构想：增加黄油附着时长，期间按目标**当前本体生命**造成伤害；免控目标可带着黄油移动和攻击，普通僵尸保留定身。

实现需要把黄油附着/伤害计时与原有定身计时分开。复用黄油贴图随目标移动，冰车单独适配贴附位置。不能为显示黄油而解除Boss硬控免疫，也不能因原定身被免疫而丢掉持续伤害。

### 已确认边界

- 每次扣血时重新读取当前本体生命，不使用最大生命、初始生命或本体加防具。
- 防具不进入百分比基线；不额外引入穿甲，橄榄的金属防具由磁力菇等专门对策解决。
- 普通目标仍正常受到黄油定身。不能把全部黄油改成不定身。
- 不使用此前的2000/2500/3000瞬间重击方案。
- 用户明确灼烧可以设伤害下限，其他百分比伤害按上限讨论；因此不能沿用曾提议的黄油最低100伤害。

### 待确定

| 项目 | 讨论过的建议 | 状态 |
|---|---|---|
| 每秒比例 | 当前本体生命1%/秒 | 未定案 |
| 伤害上限 | 尚无最终数值 | 待定，不能改成伤害下限 |
| 附着持续时间 | 8秒，黄油盛宴每层再+2秒，即8/10/12秒 | 未定案 |
| 普通定身时长 | 原4/5/6秒，与更长的附着分开 | 建议，未定案 |
| 词条位置、星级、层数 | 新增词条还是改造黄油飞溅 | 待定 |
| 重复命中 | 同名刷新、不叠加每秒比例，且不重置下一次扣血时刻 | 建议，未定案 |
| 黄油飞溅 | 额外目标是否获得持续伤害、使用何种时长 | 待定，不能自动复制完整主目标收益 |

命中反馈建议：命中时黄油拍击/飞溅，期间黄油保持附着，每跳短暂黄色闪光或滴落。控制音效和飘字密度，不让Boss停步或后仰，不反复震屏。这些表现细节需随定案效果验收。

## 4. 已确认方向、比例待定：现有灼烧

- 现有真正持续扣血的灼烧词条为樱桃「焦土」：每层300/秒，持续3秒，2星、最多2层。
- 用户要求考虑改为**当前本体生命百分比伤害，带固定伤害下限**。
- 推荐公式形态：每跳伤害=max(结算时当前本体生命×单层比例, 单层固定下限)×层数。
- 防具不计基线，实际伤害仍照常处理防具。
- 曾提议1%/秒/层、最低300/秒/层、持续3秒，但具体比例尚未确认。不能直接当作已批准数值实施。
- 同名刷新、各来源叠加、受哪些伤害倍率影响需明确；刷新不能持续推迟下一跳。

辣椒「连烧」是两次直接燃烧，火炬「引燃」「烈焰溅射」是直接伤害，不能把它们误报为已有持续灼烧。辣椒新增灼烧、百分比直伤、处刑等都是脑暴候选，没有选定实施。防重新铺冰、易伤等未被本轮选作Boss特攻路线。

## 5. 实现顺序

### 第一步：固定规则与核对当前工作区

1. 按本文保留已确认值，补齐黄油、焦土及磁力联动待定项；未定部分不凭建议直接落代码。
2. 重查PC、Android当前源码与运行目录版本，避免覆盖其他工作的修改。整理仅属于本批的备份和变更记录。
3. 本文编写时源码构建号已为71，本聊天最后交付的运行目录为Build70；后续构建号必须实施时重新核定，不提前占用71。

### 第二步：先实现已明确的磁力主干

1. 双端同步调整充磁、追加2星1层撕甲，词条ID只在末尾追加。
2. 为带撕甲的磁力菇增加橄榄Boss带盔目标分支，逐次扣3000耐久；保留无词条免疫和普通装备直接吸取。
3. 处理最后一击拆盔、头盔耗尽、多株同帧作用和目标中途死亡；避免重复拆盔或消耗空充能。
4. 使吸取动作和缩短后的周期一致，再按定案接入碎片飞掷、目标优先级与反馈。

### 第三步：按最终数值实现黄油与灼伤

1. 将黄油附着和硬控分开，使Boss正常行动时也能显示、掉血；保留普通黄油控制行为。
2. 黄油按当前本体生命和上限结算；焦土按当前本体生命和灼烧下限结算。
3. 统一处理死亡清理、重复施加、扣血节奏、伤害归属及多人同步。
4. 若新增局中状态字段，检查存档、无尽棋盘快照和联机追赶序列化；需要时提升格式版本并保留旧档读取，不能只改本地显示。

### 第四步：验证

- 磁力：充磁各层实际周期；跨行范围边界；普通装备；无撕甲Boss免疫；头盔每次3000；剩余不足3000不溢出本体；多株同时拆盔；休眠、目标消失；飞掷与优先级按定案生效。
- 黄油：普通定身、Boss移动/攻击、冰车附着位置；每跳读取当前本体生命；防具不计基线；伤害上限；重复命中不丢跳数或递归触发。
- 焦土：单/双层、当前生命递减、固定下限、正常防具承伤、刷新节奏及再生并存。
- 回归大嘴花的1/3/5口、40/8秒消化、击杀进CD、正常防具和反哺；检查新词条存档及旧档读取。
- PC和Android编译及针对性机制检查；实际窗口确认反馈，安排五人Boss实战和Android真机验证，分别记录完成与未完成状态。

### 第五步：本地交付

1. 备份放在runtime外，保护玩家档案和存档；若游戏在对局中，先保护进度再更新。
2. 将已通过检查的新版本及必要文件更新到runtime，以runtime为工作目录打开游戏，保持运行供用户检验。
3. 说明实际打开的版本及服务器、五人实战、Android安装等剩余限制。
4. 本次计划不等于发包请求；后续若要求打包，默认交付带资源和依赖的完整PC包及完整可安装Android APK，保留存档，并验证首次启动和签名。

## 6. 本轮明确排除的旧建议

- 黄油易伤、把防具加入百分比生命基线、按最大生命持续烧血。
- 给黄油或大嘴花套用灼烧的伤害下限。
- 大嘴花每口5%并最低3000的旧提议。
- 磁力一次破甲50000，以及新增词条直接吸走Boss整盔的旧路线。
- 将辣椒清理现有冰道误当成新增buff能力。

以上以用户后续明确决定为准；本计划不把未定候选批量加入游戏。
