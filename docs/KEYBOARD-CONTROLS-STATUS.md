# 种子栏快捷键执行记录

2026-10-15。Android 起点为计划提交 `d658760`，玩法来源仍固定 PC Build 46 / `8bfc67ea9c85be37cac0a182c3416f3add2c1640`。本轮不改协议、数值或存档版本，不修改 PC 工作目录。

## 已实现

- 主数字键 1–9 选择种子栏前九个槽位，0 选择第十个，Q 拿铲子。只拿起对象，随后点击草坪种植/铲除；ESC 沿原流程取消选择。
- 普通种子栏的冒险、闯关和生存接入。复用原卡片可用检查、拒绝提示、归还和工具动作；同卡重复按保持选择，不可用目标保留旧选择。传送带及特殊小游戏/工具场景暂不开放这套绑定。
- 消息/表情与送阳光先处理数字键；SDL 小键盘数字统一后也走相同优先级。数字/Q 长按只处理首次，跨面板与失焦的重复事件不会变成选植物；保留其他控件原有重复输入。
- 暂停、模态框、对白/过场、退关、特殊光标以及鼠标/触屏手势中不切卡。键盘拿卡不启动触屏拖动；Ctrl/Alt 组合不选卡。调试字符路径不再用普通战斗的数字/Q 触发速度或作弊动作。
- 使用游戏字体在卡片左上角和铲子旁显示数字/Q，Android 首次战斗键盘操作后出现。选项菜单接入中英文键位说明，普通触屏操作不弹软键盘。
- SDL 2.32.10 的 Android 表原先将 NumLock 映射为 UNKNOWN；构建脚本修正为 NUMLOCKCLEAR，并在依赖源新于已安装库时重编 SDL。输入层按 NumLock 状态把小键盘映射为数字或导航键，关闭时不合成数字字符。
- 输入提示状态置于旧 Board 保存尾部之前，未加入 Portable v4 字段表；继续读取原冒险档，不改变存档格式。

## 有限验证

MuMu Android 15，通过 ADB 键盘/鼠标输入做代表检查；这些不是完整 PC 游戏实战。

- 十卡闯关：9 拿第九张，0 拿窝瓜；再按 1 拿向日葵，按不可用的 2 保留向日葵并提示缺钱。点击种下，阳光 50→0；长按 Q 后点击铲除，未连续铲除。卡片 1–9/0 与 Q 提示可见。
- 固定 PC Build 46 原生会话验证端与 Android 连接：持第九张卡，T 打开消息页后长按 1，只收到一次 `CHAT src=2 id=1`；Android 仍持第九张，第一张未被拿起。G 后按 1，只送阳光，140→40，验证端收到 `SUN src=2 amount=90`。检查后暂停。
- NumLock 修正后，原冒险档中的小键盘 2 能进入选卡路径并显示键位提示；当时阳光为 0，沿缺钱规则拒绝。完整外接键盘布局、NumLock 关闭导航以及全部修饰键组合未做设备穷举。
- 增量 Native/Gradle 通过；最终 v2 签名及 16 KB zipalign 通过。最后一次原生改动仅把双语帮助中的范围符号改成 ASCII 连字符，以兼容英文游戏字体，随后重新构建。
- 五个用户文件已恢复到本轮开始时的备份，逐文件 SHA256 相同；验证端主动退出，本轮 ADB reverse 已移除。临时检查点、日志、截图均在仓库外。

混合触屏拖动、真实失焦/重返、教程门槛及选项菜单新增说明的完整排版仍待代表设备检查；没有重跑全部 buff 或完整关卡。早期截图期间空草坪测试局自然失败，未把失败后的按键算作通过。
