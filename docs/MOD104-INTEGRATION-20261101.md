# ByeahFeature 合并 MOD104 test

本次合并以作者 MOD104（52d7ebca）及 test 分支已验证的实现为准，升级 ByeahFeature 的运行代码。旧版实现与新观战路径发生冲突时采用 test 版本，不把 MOD95 的观战或日志钩子叠加执行。

主要内容：

- 电脑后台测试接口：当前用户命名管道、UTF-8 JSON、按实例隔离存档与设置、主线程正常游戏操作、状态查询与窗口截图；普通启动默认不开启。
- 本地模拟观战与 PWV2 精简包：缓存固定配置，保留卡槽、冷却和阳光数值，不传掉落阳光；周期／操作触发更新、增量／完全校正切换。
- 同房 P2P 预连接、超时服务器回退、隐藏进程预热、首包加载提示、大包分片重组与限速；日志与指示灯区分连接就绪和实际收到直传画面。
- 持续诊断日志、带宽与时序统计、后台双端和传输检查脚本。
- F1–F6 赠送、观战快捷键、本地菜单与 P 共享暂停、末波清场补查。

测试详情见 [小功能实测](SMALL-FEATURES-MOD104-20261101.md)、[房间 P2P 实测](ROOM-P2P-TEST-20261101.md)、[猫尾草观战](CATTAIL-WATCH-TEST-20261101.md)。合并后另在 ByeahFeature 目录全量编译 Windows x86 Release，运行代码与 test 版本保持一致。

旧 MOD95 文档和探针留作历史材料；当前构建及控制入口为 `tools/build-test.cmd`、`tools/control.py`、`tools/demo.py`，历史 `package_byeah.py` 和旧协议探针不作为本版交付入口。

合并前 ByeahFeature 未提交的末位漏怪排查修改单独保存，不属于本次提交。实测为初步验证，未完成全部模式、整关末波补查、异地 NAT 和长时间稳定性覆盖。代码全部由 AI 生成。
