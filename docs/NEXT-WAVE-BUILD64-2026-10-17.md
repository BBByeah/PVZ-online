# 下一波功能 Build 64

日期：2026-10-17。用户已确认各人控制自己草坪、10 秒冷却及防连按规则，并授权开始实现。PC 与 Android 源码同步完成；本次没有制作或部署玩家安装包。

## 玩家行为

- 闯关与无尽的正式战斗中显示底部“下一波”按钮；首波显示“开始出怪”。按钮位于伤害统计右侧、波次条左侧，触摸区域 78×46，与这两处现有界面不重叠。
- PC 支持 N 键，安卓触摸按钮可用，外接键盘也沿用 N 键。按钮显示下一波序号、剩余等待秒数，首领即将出场时显示 BOSS。
- 一次操作提前自己草坪的一波，保留场上的僵尸，不改变队友的自然出怪时间；漏怪仍按现有链路传递。
- 首波可以跳过准备倒计时。大波可以跳过长预警，立即出场，保留提示、声音、音乐爆发和旗帜状态。BOSS 仍按原来的关卡、旗波、席位与每关一次守卫生成。
- 成功出怪后冷却 10 秒，按实际战斗时间计算，游戏倍速不缩短冷却。暂停、弹出模态界面、切后台时不计时；自然出怪不重置或解除冷却。
- 一次按下只触发一次。N 键长按和系统重复按键被拦截；冷却中的操作直接丢弃，不排队。触摸或鼠标在按钮内按下、松开才触发，拖出取消。
- 按下到松开之间若已经自然出怪，该次点击取消，避免误催再后一波。冷却中按下，即使按住到冷却结束才松开，也不会触发。
- 手持植物、铲子或玉米炮瞄准时禁用。暂停、选卡、奖励、聊天／联机操作面板、伤害统计面板、观战、结算、失败时不可用；按钮点击不会穿透到草坪。
- 所有波次出完后显示“全部出场”，仍需清理剩余僵尸；不额外生成阳光、刷新植物冷却、发放奖励或直接结束关卡。
- 无尽恢复同一草坪时保留剩余冷却，恢复后不重放输入。进入新关、重打本关、无尽保留草坪原地换关时重置冷却。

## 实现与兼容

- 新增共享的 NextWaveState 和 NextWaveControl。每块草坪独立保存输入与冷却状态，构造、销毁和生成新波表时清理；没有添加 Board 实体成员，保留 PC 原生草坪对象布局。
- 提前请求在正常出怪更新中消费，复用现有 SpawnZombieWave 与后续血量阈值、波次计数、下一次倒计时、旗帜和 BOSS 处理。
- 冷却通过 12 字节可选扩展写入草坪存档，位于现有伤害统计扩展之前。PC 原生保存和 Android portable／legacy 读取路径均接入。旧文件没有该扩展时按零冷却恢复。
- 不增加联机催波消息，不向队友广播出怪命令。MOD_BUILD 为 64；协议版本仍为 1，START_LEVEL 仍为 44 字节，检查点版本仍为 20。
- Android 编译时发现已有 ToggleOnlineSeedsReady 定义缺少头文件声明，补齐声明以完成双端验证，未改变该准备功能的行为。
