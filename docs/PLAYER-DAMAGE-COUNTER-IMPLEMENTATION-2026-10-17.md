## 玩家可用设计

- 首版覆盖单机/联机闯关与无尽，不包含原版冒险的僵王统计。
- 无设置时默认“本关”；高级选项可选“本关 / 本轮”。首版实现默认显示总伤害和BOSS两个摘要，可分别关闭。这是实现默认值，不另称玩家已定案。
- 两种伤害各有入口和详情面板，同一时刻展开一种；**总伤害包含BOSS，不能把两项相加**。隐藏摘要、切换范围均不清数据，后台仍累计。
- 紧凑入口位于800×600画布底边：统计(184,568,54,26)、总伤害(242,568,124,26)、BOSS(370,568,124,26)。摘要用K/M/B/T/P/E缩写，详情显示完整整数，数字列按宽度缩小字体。
- 点击“统计”进入局内高级选项，任何玩家均可修改本机显示，不代替房主改出怪规则。开局高级选项也有同样设置：PC第5页、手机第4页。
- 详情按当前席位顺序显示，每页6行；离开玩家保留最后记录，历史过多时翻页。离线、未同步及历史不完整有标记，未收到的数字用“--”，不冒充实时精确值。
- 沿用原石材及绿色/亮绿色艺术字；固定按钮标签已静态核对两个原字库，未新增资源或补缺字体。手机只触控，不显示键盘字母。
- 面板非强制弹窗，不自动暂停。暂停、聊天、赠送阳光及观战期间不抢操作；按下/松开、失焦和手机种卡拖动有独立拦截。
- 本批不增加快捷键、每秒伤害、逐株排行、跨局排行榜或独立关后结算页。最后记录保留在应用内；进入下一关后“本关”切换新关，不提供上一关历史浏览。独立结算摘要仍是后续界面项，不能宣称已完成。

## 计量出口与来源

应用持有独立 DamageStats，双层64位总伤害/BOSS子集，累计上限2^63−1；不使用游戏随机数。Board、Zombie、Plant、Projectile、Music不新增统计数据成员，不改变它们原始字节保存布局。

| 类别 | 源码接入 |
|---|---|
| 普通弹体、穿透、溅射、紫卡波 | Projectile更新、命中、溅射和波函数建立玩家来源；Zombie分层实际扣血处只记一次 |
| 近战、地刺、倭瓜、范围炸弹 | Plant更新与DoSpecial建立来源，统一进入扣血出口 |
| 吞噬、缠绕、灰烬秒杀、冰车/投篮车摧毁 | 对仍存活目标折算剩余本体、有效头盔/盾/飞行耐久；池ID含代次去重，保留雪橇连带击杀 |
| 焦土持续伤 | Zombie自然更新默认非玩家，只有焦土扣血段显式归玩家 |
| 反伤、地刺反击、冰冻陷阱 | 显式玩家来源，实际减血计数 |
| 魅惑僵尸啃咬、巨人、自爆及辣椒攻击 | 仅魅惑攻击者建立玩家来源；友方目标受击不记 |
| 借用、接力 | 本机草坪的攻击归本机玩家；接收/移出和血量初始化不补算上家伤害 |
| 脱盔、磁力摘装备、吹走、再生和治疗 | 不从每帧字段差值推算；移除/控制不是伤害，治疗不倒扣 |
| 小车、自然掉血、敌方攻击、清理及接力移除 | 无玩家来源，不计；拆棋盘前解除统计目标，防止植物清理回调误记 |

本体、盾、头盔、飞行耐久在原扣除前读取实际可消耗部分；过量、已死亡及过场对象计0。低血灰烬与普通伤害分支分开，避免既记全血秒杀又记扣血。

BOSS沿用 Board::IsRunBossZombie，覆盖带标记的红眼、橄榄球和冰车，以及接力、多只并存、最后一击；普通同类型怪与召唤物不因类型相同自动算BOSS。不改攻击、减伤、血量或死亡流程。

以上是挂点审查，不是攻击覆盖测试通过。

## 联机与身份

- 新增MSG_DAMAGE_STATS=24，独立定长134字节，显式小端编解码，不直接发送结构体。
- 带来源/目标席位、BEGIN/REPORT/RELAY操作、模式、种子、关号、尝试标识、玩家身份、序号、两种范围的总伤害/BOSS值和64字节UTF-8名字。
- 本机负责本机草坪；每秒绝对快照，关卡保存、失败及拆棋盘前尽力补发。房主校验真实来源席位与mCoopPeers身份，汇总后转发；接收只覆盖更新序号，不重复累加。
- 房主BEGIN定义尝试代次；新代次清远端序号。关卡切换清待收队列；普通数据必须匹配种子、模式、关号和尝试。TCP顺序控制帧不做伤害累加。
- 以会话身份而非名字/席位做行键；换位更新席位，检查点恢复本机行后映射当前会话身份，离开玩家保留历史。上限32个身份记录，当前房间最多6席。
- 校验BOSS≤总伤害、本关≤本轮，以及扣除本关后BOSS仍不大于总伤害；64位上限、长度、操作及序号受限。收件队列最多128包。
- 只给Build63及以上队友发新消息；旧端无统计包，混合版本不保证完整表。服务器现有游戏消息区间和来源检查可转发24，无需本批部署服务器。
- 普通合作统计，不是服务器逐帧复算的防作弊系统；断线或末包缺失只显示最后同步值。

- 检查点v20在v19内容后追加长度受限、双重校验的统计块；仍读取旧版本，包括19。统计块损坏/缺失只降级统计，不因附加统计损坏拒绝有效进度。

- 普通闯关从关首检查点重开，保存关首统计基线；通过后保存本关新增并累计。失败/重试不把失败段反复叠入通关历史。
- 新无尽单机关中继续使用实际草坪与同步统计；联机关中按现有草坪基线重入，统计同样使用基线。失败回退与RetryLawn内嵌统计保持一致。
- 无尽原地续关不建新Board，故在InitEndlessRunStage另接BeginLevel，避免本关数字跨关累加；本轮值保留。
- 旧档历史无法补算时标记不完整；不捏造启用前数字。恢复的新关只清本关，不清整轮。
- 本机偏好单独保存：PC注册表ModDamageStats，Android应用私有userdata/android-damage-stats.txt，默认位包6；偏好保存失败不应用新值。开局页与局内入口共用同一设置。
