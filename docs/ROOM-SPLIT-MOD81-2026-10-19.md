# MOD81：单人 / 局域网与服务器房间分离

## 玩家可见变化

- 组队面板先选择“单人与局域网游戏”或“服务器房间”，不再混排地址、建房按钮。
- 自己玩不需要服务器：左侧有明确的单人入口，局域网只用于同一网络的朋友直连。
- 服务器房间只用于远程组队。允许先建大厅等人，但至少两名真实在线玩家才能开始；离线保留席不凑人数。
- 已建房又想自己玩，可以确认退房后进入单人；不会暗中把服务器对局转成单人。
- 战斗失去最后一名队友时草坪停止推进，保留本局等待归队；重连最终失败也不会自动丢弃草坪，可明确“保存并退房”。
- 使用已有石质按钮与艺术字资源，不替换或删除原版美术。
- 本次基于当前主线 MOD81 构建，包含工作区已有修改，不把独立工具插件加入标准包。

## 验证记录

- PC Release 与 Android arm64 原生库、完整 APK 构建通过。

- 截图使用真实游戏资源绘制；PC 本地原生专项不等于 Android 真机触摸验收。
- Go 中继全套测试通过，包含在线人数、离线席、客户端伪开局、旧关放行与下一关等候名单检查。
- APK v2 签名验证通过，与此前 MOD66 正式包证书 SHA-256 一致；应用ID仍为 io.github.pvzonline.android，版本码81。覆盖安装时不要卸载旧应用。
