# 开局设定页（MOD82）

## 用户定案

- 只显示本局开局时选择的设定，页面只读。
- 不显示当前关累计倍率、动态战斗效果、已取得词条或伤害数字。
- PC 与 Android 同步提供，保留原有帮助、词条、音乐入口，不替换原版艺术字或美术资源。

## 入口与内容

进入闯关或无尽后，打开局内选项，点击独立小石按钮“开局设定”。英文按钮为 Setup。没有正在进行的闯关时不显示该入口，不读取主菜单默认选项冒充本局设定。

每页最多七行，提供上页、下页与返回按钮。PC 可使用左右键、翻页键及滚轮，Esc 返回原选项；触摸按下后移出按钮再松手不触发操作。

普通闯关显示十一项：模式及总关数、出怪难度、出怪规模、波间隔节奏、首波出怪、植物僵尸、巨型BOSS、增益倍选屏数、场景难度阶梯、僵尸移速成长档、每新场景僵尸强化条数。

无尽显示十四项：模式、规则版本、开局场景、出怪难度、出怪规模、波间隔节奏、首波出怪、植物僵尸、周期BOSS、增益倍选、每五关移速成长档、每五关僵尸强化条数、阶段主题开关、阵容偏好开关。无尽不展示未使用的场景难度阶梯；旧版无尽不会被标成启用新版周期BOSS或主题。

只读本局 RunState 中的固定配置，联机读取已同步到本局的房主设置，续档读取检查点中的配置。不另建配置、修改存档格式或变更联机协议。本机划取、血量、音乐及可随时更改的伤害显示选项不冒充固定开局设定。

## 检查与交付

- 在独立 build-ui-settings-x86 构建目录完成 PC Release 构建，避免和其他任务的共享构建互相覆盖。
- 使用真实引擎与资源验证中英文、各模式/场景/倍率、首波和阶梯的非顺序枚举、旧版无尽、只读性、翻页、按下移出、返回、反复开关、存档往返及房主 AlignRunToHost 取数。
- 测试档案、语言注册表均隔离于玩家正式数据。页面预览用支持文字合成的内存图片；图鉴水面测试不能套用该渲染目标。
- 主要证据：tools/audit/setup82-handoff.json、setup81-data 内最终中英文日志及截图、setup81-pc-build.log。setup81 是开发审计名，当前实际版本沿用 MOD82。
- 最终双端完整包及 runtime 更新由 MOD82 合并发布任务统一执行；须保留服务器任务的多服功能、帮助页作者链接以及本页。当前页面专项不等于手机真机或公网长局验收。
