# Build75：荷叶与花盆互相叠种

按玩家要求，PC与Android同步实现：荷叶可种在花盆上，花盆可种在荷叶上；同格各限一株。屋顶先种花盆即可放荷叶，水里先放荷叶即可种花盆；闯关草坪两种顺序均可。

两种底座分别识别，上方仍可放正常植物；花盆与荷叶叠放后，也可在其上放海蘑菇、缠绕海草。已有上层植物或南瓜保护时不能插入第二种底座，冰道、弹坑、墓碑、越界等原有限制保留。裸屋顶不能直接放荷叶，裸水面不能直接放花盆。

后种的底座在上层，铲除、啃咬、蹦极优先处理上层；有普通植物时仍优先普通植物。移除上层后保留下层。显示层次和高度跟随叠种顺序；香蒲升级准确找到荷叶，保留同格花盆。禅境花园原有规则不变。

`PlantsOnLawn`是临时查询结构，仅新增两种底座的独立指针；植物对象、协议与存档结构未改。已有保存的显示顺序承载叠放顺序，实际保存读取检查通过。双端构建号75，联机客户端需统一版本。

验证：PC x86 Release、Android ARM64原生库编译通过；加载实际资源、调用生产引擎的专项33项、0失败，覆盖双向叠种、各限一株、顶部选择、普通植物优先、上层移除保留下层、屋顶及水面承载、被蹦极抓住的荷叶不能支撑新种植、香蒲查找下层荷叶、冰道/边界、非闯关及保存读取。专项使用隔离测试档案，未修改玩家存档。
