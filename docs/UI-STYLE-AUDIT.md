# Android 非原版风格 UI 清单与替换准备

2026-10-14。源码检查当前 Android 分支；用户要求先记录并准备改，本轮不整体重做美术。

| 界面 | 当前实现 / 问题 | 后续替换方向 | 优先级 |
|---|---|---|---|
| 主菜单「闯关」「联机」 | `GameSelector.cpp` 的普通 ButtonWidget，纯绿色矩形 | 原版木牌/墓碑按钮；保留现有位置与触屏面积 | P1 |
| 闯关模式与高级选项 | `RunFlowScreen.cpp`，全屏纯绿底、矩形选项按钮 | 原版对话框/图鉴底板，模式木牌、明确选中态；中文与十个以上选项需排版 | P1 |
| 植物/增益奖励、重摇与跳过 | 同一 RunFlowScreen，植物仅文字；纯绿矩形选择项 | 植物用种子卡，增益用图鉴式说明卡，重摇标价/金币口径对齐 PC | P1 |
| 联机房间 | `OnlineDialog.cpp`，纯绿底、白色编辑框、普通按钮 | 原版联机/墓碑面板及石材按钮；主机 IP/服务器分开、房间码和席位流程保持 PC | P1 |
| 邀请、等待就绪、掉线重连、联机通知 | `OnlineStartDialog.cpp`，共用纯绿矩形底与按钮 | 复用原版 LawnDialog 九宫格和石材操作键，按内容调整高度；等待框不可意外放行 | P1 |
| 语言按钮 | `NewOptionsDialog.cpp` 的普通 ButtonWidget，置于已有原版选项框中 | 原版按钮素材，CJK 字体保留；自动/中文/English 和重启生效语义不改 | P2 |
| Android 资源管理、导入/导出与启动 | ResourceImportActivity + `activity_resource_import.xml`，系统控件/纯绿底 | 游戏主题的本地资源管理页；资源未导入时也能展示，不能依赖缺失的原版素材 | P2 |
| 新增手机协作入口与面板 | 本轮新增：消息、表情、阳光三个入口 | 实施时直接复用石材按钮与植物种子图，避免再新增纯绿临时皮肤；后续纳入统一布局 | 本轮 |
| 僵尸投票面板 | Build 46 同步新增的依赖 UI | 使用相同石材/卡片绘制基础，规则与 PC 一致；加入统一皮肤清单 | 随同步 |

原版标题、主菜单主体、选卡、图鉴、商店、普通提示/暂停框已使用游戏素材，字体补全不是非原版皮肤。Android 系统文件选择器、权限与系统确认框保留系统样式，不尝试覆盖系统操作。

## 准备工作

1. 汇总玩家资源中已有对话框、木牌/石材按钮、种子卡和金币图；仅引用现有资源，不把原版素材提交仓库。
2. 提取可复用的石材按钮、面板背景、CJK 文本与触摸命中逻辑，业务动作继续使用现有接口。
3. 先替换主菜单入口与房间，再替换模式/奖励页，最后调整资源管理和零散控件；同时维护中英文、按下/禁用/选中态。
4. 五行/六行草坪、十张种子卡、手机缩放和文字溢出各做代表检查。皮肤改动不重写状态机，不为可逆美术变动建立大规模测试。

本轮先完成协作功能及必要的版本同步；未将整份清单标为已替换。

本轮协作按钮/面板已经使用石材与原版对话框纹理，投票框使用 LawnDialog 背景；其它 P1/P2 项仍待整体替换，不能把这一批功能接入称为全部 UI 风格已完成。

种子卡 1–9/0 与铲子 Q 的提示已使用游戏字体，在卡片角落/工具旁绘制；Android 使用键盘后显示，卡片提示代表画面已检查。双语帮助的完整排版及真机组合输入继续检查，见 [快捷键结果](KEYBOARD-CONTROLS-STATUS.md)。
