## U01 共用控件：先改这一处

像素探查：loan-ui.png 的(366,351)、(400,375)、(850,350)为RGB(95,97,129)，(850,380)为(94,96,128)。当前字色源码为(30,75,15)，用标准sRGB相对亮度计算，对比约1.67–1.70；改(245,230,165)后约4.77–4.84。这是背景实测加源码字色计算，未测整幅纹理或字形边缘，也未产出修改后的运行截图。脚本和机器可读记录见 `docs/ui-evidence/build52-audit.ps1` / `build52-audit.json`。

- 字色基准：普通(245,230,165)，按下(255,246,210)，次要正文(205,205,190)放在深内容底上；需要时1px深色阴影，不用荧光绿描边。禁用不能继续把灰字放在同亮度石材上：压暗表面但维持标签可辨，并在邻近状态行解释原因。
- `MobileStoneButton::Draw` 当前忽略各调用处SetFont/SetLabelColor；统一在helper实现状态/字体策略，避免调用处改了却无效。增加明确selected参数或单独选择卡绘制函数；pressed是手指暂按，selected是持久选择，不能混用。
- 文本按钮字22–24，正文20–22，重要标题28–32；16只留给次要短说明。达不到宽度先两行或截短+详情，不要不断缩字。
- 长队友名：单行截断保留席位编号，动作单独第二行；不要截掉“赠送90”后只剩名字。中文和英文都走实测StringWidth，并设置局部裁剪。
- 控件触摸目标原则≥44×44逻辑像素，字离石边≥12px；缩放1.8只用于截图，不等于真机dp保证。真机触摸仍需代表检查。

## U02 协作页：可直接落地的区域规格

保持800×600模态容器和既有Blocking/Close/Mouse*路由。建议只在此对话框定制一次面板背景 `Rect(20,20,760,560)`，标题放内容内；不要全局改LawnDialog。当前LawnDialog标准框从y45开始又带顶部骷髅，标题却手工画在y40，截图出现边框/标题挤压；可在该页用DrawMobilePanel替代标准背景，避免底层奖励页边框露出干扰。PC分支要选用自身面板绘制能力，不能直接引用Android头。

| 页脚 | (48,502,704,48) | 左返回(48,502,130,48)，中分页或主动作，右状态。请求阳光按钮仅在战斗显示；准备阶段放借用说明，避免一个灰按钮长期占据主动作位 |

植物缩略图复用 `DrawSeedPacket`（`SeedPacket.h`已导出）或现有CoopEmote的Plant绘制，不创建真实Plant。借用无永久解锁，应在图旁标“本关借用”，不要放成永久奖励卡。

借入成功页要显示“豌豆射手 · 本关借入”，下方以 `GetEffectiveBuffCount` 对照 `GetBuffCount` 展示有提升的专属词条，例如“连射：1→3”；无提升写“可使用该植物，专属词条无额外提升”。`mLoanBuffs`有层数，来源名目前不持久化，未保存来源不能伪造“来自某人”。长词条超过区域需翻页/滚动，保留关闭和取消可见。出借确认仍要有明确同意/拒绝两个按钮。

**必须如实表达可借范围**：现有wire没有队友永久卡池/完整词条目录，植物列表当前只能表示“申请此植物”，不能把48株都画成“对方可出借”。先保留“队友须拥有，由对方确认”，申请被拒给原因；“只看队友可借植物”需另做目录消息，属于后续协议工作，本轮UI不擅自加。

队友有求援时显示“赠送90（消耗100）”，没有求援且在准备阶段才显示申请借用；战斗时无求援显示状态，不能一面写“申请借用”一面点击后才说不能借。接收者与赠送者阶段不同也要按本地可行动状态灰置。

## U03 战斗入口：少遮挡，保留所有动作

- 首选常驻一个“队友”石材按钮，候选 `Rect(4,92,72,44)`，位于种子栏下方左边界；这只是候选，六行/屋顶和十卡布局必须看一张代表图确认。不要继续在推车上竖排5个按钮。
- 点击后开工具盘，建议 `(88,98,444,136)`，两行：消息、表情、赠送、观战、协作/借用；保留100→90旧赠送与新求援的区别。求援收到时入口显示小提示点/“求援”，不自动弹全屏挡操作。
- 观战占用全屏时仍使用现有顶部“换人/返回”，不要再叠工具盘。选人、消息、协作打开时关闭上一盘，避免两层X和返回语义混乱。
- 不是单改坐标：`CoopHit / CoopMouseDown / CoopMouseUp / CoopAction / DrawCoopUI`需一同检查。不要更改已有动作ID含义或吞掉键盘T/G/V/B路径。按住卡片打开后不得落种到底层。

## U04 房间：先重排内容，再换输入框皮肤

房间是750×550局部坐标，居中后才映射到800×600；不能把CoopDialog的坐标照抄进来。保留 mAddress/mServer/mCode 和按钮ID1–7、Enter和IME停止行为。

- 标题内容边距44，状态行在标题下24px。未连接时用2行简短引导填充顶部：“服务器房间：填房间码与朋友联机 / 直连：同局域网或已配置网络时使用”，不提前摆空的六人名单。
- 中部使用两组：服务器（服务器地址、房间码、创建/加入）在上；直连（主机IP、建房/加入）在下。每组标签/输入/动作对齐，共用12px间距；先做分组不引入新tab状态机。
- 连接后顶部区域替换为紧凑两列席位条，状态/房间码优先于本机IP。名字局部裁剪，房主标记不被长名挤掉。
- 输入保持EditWidget可聚焦：深色填充、暖灰文字、内边距、焦点金线；房间码留足输入宽度。画法若由EditWidget统一控制，只为此页增加可选主题，不全局改所有输入控件。
- 底部固定“断开 / 关闭 / 房主开始”，关闭保留连接。当前提示画在y461、按钮y475，建议将说明留在内容区并包行，英文不得穿过按钮。

1. 沿用原版石材、木牌、种子卡、图鉴面板；不提交PopCap素材，不为此次整理另造一套现代扁平控件。
