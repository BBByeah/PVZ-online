# 双端 UI 第二批：协作快捷操作与同页借用

2026-10-16。沿用 Build55 / Protocol1，检查点v17，`onlineGameReady=false`。整轮范围见 [总计划](UI-REDESIGN-PLAN-BUILD55.md)。第三批接续状态见 [第三批状态](UI55-BATCH3-STATUS.md)，第四批主菜单/模式/奖励/结算仍待实施。

## 本批实现

- PC、Android采用相同的 `CoopHud.h`、`CoopPlayDialog.h`：原版石材、植物种子卡，中文/英文文字；共用绘制与命中矩形。
- 战斗右上常驻消息、表情、阳光三个按钮。消息/表情点入口后点项目即发出并收起；阳光点入口后点有效队友即按旧规则扣100、到账90，不加成功确认框。余额不足也能打开求援面板。
- 求援、响应、主动赠送放在同一阳光面板，费用、冷却、离线、等待到账回执可见。等待回执时不允许再扣一次；响应求援与主动赠送采用不同点击动作，防止请求在按下和松开之间过期后误变成主动赠送。
- 借用在同一页选队友、选植物、发送；必要的4次操作内完成，不自动选择队友、不选植物即发送。植物目录明确说明由对方确认是否拥有，不伪造远端库存。完整词条按需翻页，实际层数读取既有永久/借入取最高规则。
- “收起”只关页面，保留申请；“取消申请”走原取消事务、显示待确认并限制新申请，收到回执才显示确认。准备/选卡页入口会显示借用申请、待答复、取消待确认等状态。
- 高频面板只捕获自身矩形，外侧草坪保持操作；按下/松开须落在同一操作。赠送另核对同一玩家身份，防止席位换人误送。拖出松手、关闭、失焦后的迟到松手均不得落入草坪种植。
- PC保留1–9/0植物、Q铲子、T/E/G/B/V等既有键盘路径；新增鼠标观战后可点换人/返回，按住V的原路径继续保留。

## 布局与操作预算

800×600逻辑画布。十卡种子栏右边599；仅联机局把铲子区放604..652；三个44×44入口在660..796、y40..84，位于菜单按钮下方。离线花园/工具位置不变。石材左右端素材原宽36+35，新小按钮将两端各约束至宽度三分之一，避免负宽中段和超出命中区。

| 操作 | 本批路径 | 页面切换 / 额外成功确认 |
|---|---|---|
| 消息、表情 | 入口→项目，2次 | 0 / 0 |
| 主动送阳光 | 阳光→有效队友，2次 | 0 / 0 |
| 求援 | 阳光→请求，2次 | 0 / 0 |
| 借用申请 | 借用→队友→植物→发送，4次 | 0 / 0；翻植物目录另计 |
| 同意/拒绝 | 申请入口→答复，2次 | 0 / 0；详情翻页另计 |

消息面板480×336，占画布33.6%；阳光480×302，占30.2%；表情480×284，占28.4%。关闭后只留三个入口。短通知最多两行52高，面板打开时通知限制在左侧302宽，不覆盖面板内按钮；到账回执等待优先于普通聊天。借用为准备阶段的大面板，收起不取消准备门。
