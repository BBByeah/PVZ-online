# 双端 UI 升级实施交接

2026-10-16，Build55 / Protocol1。总范围见 [双端UI计划](UI-REDESIGN-PLAN-BUILD55.md)。本次为第一批：共同控件、房间、席位与准备/重连提示。后续协作、词条、主菜单/模式/奖励/结算尚未完成，不能把第一批当整轮完成。

## 第一批改动

- 双端新增相同的 `OnlineUiDraw.h`、`OnlineRoomLayout.h`，复用原版石材和对话框素材，文字固定可读字号，长状态换行而不是缩到小字。绘制使用局部 Graphics，命中与绘制共用矩形。
- 未连接：云中继服务器/房间码和创建/加入为主要操作，局域网主机IP与直连按钮另组，端口97/27777明确分开。已连接：隐藏不可编辑的连接配置，改为六席概览、房间码、身份、席位/断开/返回/房主开始。
- PC增加房间内的房主开局入口，调用已有RequestAdventure排队，不复制开局状态机；客户端与已有棋盘时不可发起。手机保留ShowRunMenu，增加同样阶段守卫。返回保留连接。
- 六席详情显示本轮“已准备/尚未准备”或离线保留，房主等待ACK时只显示真实已知的待答复状态；不推测对方具体在选卡还是选奖励。
- 准备等待条为672×140，800×600画布占位约19.6%；手机原通知框660×310，占位42.6%。原画布和模态准备门不变，大幅缩小显示占位不等于允许未准备开战。
- “查看席位”从等待条一次点击打开；“返回等待”一次返回，不经过房间。全员准备放行或本机重连时，等待来源的席位详情自动关闭，避免残留模态页挡住开场。
- 重连也采用672×140实时状态条，显示房间、尝试次数、剩余时间和退出操作；仍走既有OnlineReconnectCancelled/暂停语义。
- NetSession仅新增只读查询，匹配readyEpoch，不消费ACK/RUN_GO、不改线协议和玩法逻辑；空席、离线、当前轮未准备分开显示。
