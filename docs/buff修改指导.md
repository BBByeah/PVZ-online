## 3. 用户取向：如何提出更容易被接受的buff

这些是归纳，不是用户不可变的规则。

1. **让人想拿**：单条收益要能感知。二星可以很强，星级不应只按伤害大小机械排序。
2. **强化植物自己的特点**：三线处理空道浪费、分裂利用后嘴、土豆雷扩雷、路灯支援整行，比通用“伤害+一点”更符合本轮选择。
3. **喜欢明确的机制变化**：改变出手、覆盖、种植、资源循环或布局条件；避免一串难解释的临时状态。
4. **允许强力循环与组合**：明确允许子雷继续繁殖，也允许百分比伤害随攻速多次触发。不能因为“可能很强”就私加断链、每秒额度或层数上限。
5. **也会主动削去过强控制**：删除震雷、暂不扩魅惑菇、否决强控候选；因此不能归纳为“所有东西越强越好”。
6. **愿意用代价换特色**：钢壳南瓜耐砸但血量减半；忧郁菇孤高流让周围留空。要求独立生效，不等于无条件生效。
7. **认可Boss特攻，但不希望单次直接秒杀**：蚀心孢子为5%当前生命，Build65用户将单次额外上限由800提高到5000；不是全面禁止高DPS或多株集火。
8. **明确规则比隐藏补丁重要**：固定频率、固定反伤、当前/最大生命、基础/额外伤害都要分开说清。

## 4. 星级与叠层的指导

- **1星**：直接、实用的小功能或补短板，例如坚果包扎、仙人掌20%移动减速。不要把几乎无用的东西塞进1星。
- **2星**：有明显对局收益的强化或机制，例如3000血消化回血、固定1000反击、钢壳、整行易伤、蚀心孢子。百分比伤害不自动等于3星。
- **3星**：优先表达打法变化/植物质变，例如雷区繁殖、空道火力调度、持续喷射、孤高忧郁菇、坚果变保龄球。具体星级仍以用户对该条定案为准。
- 本轮MOD48新增/重做、疾雾、蚀心孢子、孤高、保龄球均最多1层。**这不是“全游戏buff一律1层”的规定**。
- 当前仍有无限叠层条目与既有限层条目。后续全局削弱讨论中，用户否决了新增层数上限的方案；不能把“不新增上限”误读成“删除所有旧上限”。
- 最新全局定案：只将火力每层+30%改为+20%，无限层数、2星保留；其他全局词条维持现值，不额外加上限。急袭/丰饶等既有cap仍按源码。

### 大喷菇：MOD49，原ID19重做

用户原话：“大喷菇三星buff改成一直喷，每秒5次伤害，不受攻速影响”。

- 三星疾雾，最多1层；每20游戏帧一次伤害（100游戏帧/秒），原基础20点/次，基础100伤害/秒/目标，射程340px不变。
- 无敌人也喷；睡眠、压扁、蹦极等仍遵守原停攻规则。
- 急袭、暮光、旧疾雾多层均不提高它的伤害频率。
- 精准、战线照明、伤口加深仍可增伤；腐臭之息正常刷新减速。
- 火力本来只增子弹伤害，大喷是范围直接伤害，不因此获得火力收益。
- 升级成忧郁菇后使用忧郁菇机制，不继承大喷疾雾。不能把固定频率误推广到所有植物。

### 胆小菇：MOD50，新ID109

用户要求对Boss有一定特攻、避免秒杀、定2星并让人有拿的欲望；在讨论后最终原话：“5%，最高800限伤，就这样，实现”。

**Build65当前公式：额外伤害 = min(5000, floor(命中前目标当前本体生命 × 5%))。** 用户于2026-10-17将原800上限提高到5000；基础孢子伤害另外保留。2星、最多1层。

- 5%基于当前生命，不是最大生命，不计头盔和盾的血量；5000限制额外部分，不是整次总伤害。
- 对Boss也生效，但不穿过原本不可受击的阶段。不是执行/斩杀/直接扣百分比总血条。
- 百分比部分不吃火力、精准、易伤倍率；基础伤害照常受益。两部分在倍率后合并为一次受击，再走护心和护甲，不穿甲，不拆两次绕盾。
- 攻速可增加触发次数；**没有每目标每秒共享额度**。先前agent提出的3%、2%、每次100、每秒300都未成为最终定案，不得重新装回。
- 仍会缩头；与无畏、磐石独立兼容，不要求先拿它们。
- 小喷菇和胆小菇共用孢子弹型，必须认来源植物，不能按弹型给所有孢子加伤。

## 8. 组合与重复审查：每次提案至少说明这些

1. **和已有哪条不同？** 同一株已有条目、同效果其他植物和全局都查。不要为了“每株1–3条”硬凑；这是初始脑暴目标，不是每株配额。
2. **单拿如何生效？** 给一个没有其他buff的实际使用情景；写清触发是否频繁到值得拿。
3. **与现有流派怎么配？** 如三线齐射/贯穿、分裂背刺、消化/连吞、反伤/耐砸、黄油控场、灯光支援、产币/重摇、孤高回血、保龄球掉币。
4. **组合是否让一条静默失效或异常倍增？** 明确倍率、加算、递归、命中次数、目标数、无敌阶段以及控制刷新规则。
5. **互斥是具体ID之间的关系，不是同株一刀切。** 冰西瓜化与寒冰贯通互斥，冰晶分裂可与任一路线配；加农炮转化与黄油盛宴/黄油飞溅互斥；保龄球分别排除两条站桩条。
6. **存活与防御规则怎么处理？** 非关底Boss巨人与关底Boss分开；反伤是否先结算、击杀后还砸不砸、护心是否适用，写清实际执行次序。
7. **有意保留的强组合不要私砍。** 子雷繁殖、攻速触发百分比等已明确允许。若实测出现新问题，带证据提出调整，让用户决定。

## 9. 给用户提案的推荐格式

每批少量推荐；每项写：植物/名称、效果一句话、精确数值与星级/层数、单拿收益、与现有buff关系、Boss规则、实现难度、需要用户拍板的选项。先自己筛掉明显不行的，再请用户逐条讨论。

涉及重大歧义（当前/最大血量，基础/最终血量，是否递归，单次/每秒上限，额外/总伤害，Boss是否生效）应及时询问。已有清晰定案则直接推进，不重复要许可。不能把agent的“我建议”升级成用户的“我决定”。
